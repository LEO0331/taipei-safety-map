# 臺北市橋梁檢測與維護證據查核決策支援 — Policy #9

## 1. 政策問題

有限行政查核量能應先釐清哪些公開橋梁紀錄的身分、檢測文件、維護欄位與地理來源差異？本 POC 提供可重現的查核名單，不提供結構危險排名。

## 2. 預期使用者

行政查核人員、資料治理人員、政策研究者及需提出有來源依據問題的公民。最新工程狀況仍須向主管機關查證。

## 3. 來源清冊

A「臺北市橋梁檢測及維修資料」與 B「臺北市橋梁資訊」，發布機關為臺北市政府工務局新建工程處。原始檔、官方目錄 HTML、雜湊與接受紀錄分開保存；其他參考網站未加入身分對帳。

## 4. 官方版本

A 資源更新於 2025-06-23 15:55:02；B 於 2025-12-16 09:41:34（臺灣時間）。2026-10-23 重新下載的 A 與舊檔逐位元組相同。原始 A 取得時間未知；不以檔案修改時間代替。目錄中繼資料更新日期另列，不當作檢測日期。

## 5. 統計單位

A 為 416 來源列、415 來源內分組；B 為 612 清冊列、612 不同 ID、413 不同非空 bridge_id。157 列 bridge_id 空白。分組、清冊列及 bridge_id 數都不是認證的實體橋梁總數。

## 6. 橋梁身分對帳

僅正規化空白、全半形及臺／台；保留方向、括號、編號與後綴。名稱、行政區、主管機關必須唯一且相容；多個候選、重複識別碼、多筆檢測指向同一清冊列，都不得偷偷接受。實際結果為接受 216、歧義 5、排除對應 18、無名稱對應 177。接受者是「本版研究對應」，不是官方確認交叉表。

## 7. 年度與檢測週期

民國／西元年保守解析，月、日未知。可顯示分析年與公開年度差，但不能據此判定逾期。B inspect_rate 為月／次；實際適用週期、豁免、檢測事件日期與最新現場紀錄未被這兩份資料證實。

## 8. 維護紀錄語意

314 列未公開維護年度，317 列未公開經費；這不是「未維護」或「零支出」證據。只有來源明確的零才解析為零。維修經費不轉換成狀況指數。

## 9. 地理驗證

檢查數值、軸向、臺灣／臺北粗範圍、行政代碼與物件／端點的粗略一致性。未使用行政區多邊形，不能聲稱行政界線已驗證。官方物件參考點不必然是橋梁中心、入口或測量線形；端點不自動連成認證橋軸。

## 10. Mode A 文件級別

第一個符合規則決定級別：A 身分或文件衝突；B 文件完整度問題；C 例行文件查核。實際 A=23、B=393、C=0。所有檢測結果術語的工程分類意義均未獨立查證，因此 C 級為零是合理結果。級別不是結構安全分級。

## 11. Mode B 地理門檻

接受身分對應且通過物件座標與類型篩查才可進入。216 筆接受對應中，22 筆所對應清冊類型不屬橋梁，故合格數為 194。獨立清冊層可呈現 580 筆橋梁參考點，未附檢測結果。箱涵 28 與其他 4 列保留稽核、排除地圖。

## 12. Mode C 安全門檻

不可用。缺少構件缺陷、正式工程報告、載重評等、設計容量、劣化歷程、工程完成與現場限制等證據。不得以缺漏、年度、尺寸或支出推論危險或失效機率。

## 13. 候選粒度

每一來源列都是文件查核候選。識別碼包含來源版本雜湊、來源紀錄列號及原始欄位雜湊；不以橋名當永久主鍵。保留來源序號、分組、對帳狀態、清冊識別碼、問題碼及地理資格。

## 14. 選取方法

先套用資格及篩選，再依 A/B/C 與穩定識別碼排序。平衡行政查核按公開行政區字串 Unicode 順序輪流取一筆，區內仍依級別／識別碼排序。跨區字串保留為原始行政分組，不強行指定單一區。

## 15. 名額情境

提供 5、10、全部符合資格。5 名額證據缺口優先為 5 筆 A 級，涵蓋 2 組；平衡策略為 2 A＋3 B，涵蓋 5 組。10 名額分別涵蓋 5 與 10 組。名額是文件查核工作量，不是修繕預算分配。

## 16. 敏感度

比較全部來源列、嚴格接受、接受＋歧義（僅文件）、接受＋座標；也比較僅 A 級、5／10／全部及兩種策略。顯示實際選取、共同、新增、移除識別碼與資格人口變化。較寬身分範圍不授予地理資格。相同結果也如實呈現。

## 17. 真實發現

安泰橋為可接受研究對應與地理範例；康樂橋有歧義；社教館人行地下道無名稱對應且經費缺漏；中正橋缺少檢測年度；康忠橋身分接受但地理類型排除。水源高架匝道C 是未接受對應的清冊範例，bridge_id D021 重複。詳細原始序號、列號、區／機關、級別、來源版本及問題碼見 `bridge-policy-results.json` 與英文身分合約。

## 18. 工程架構

獨立 fetch／audit／build 管線、型別化來源與情境引擎、內容定址快照、雙語 React lazy 模組、既有 Leaflet 地圖、20 筆分頁與 JSON／CSV 匯出。只在進入模組才取得政策資料，瀏覽器不向官方 API 抓資料；原橋梁目錄與其版本保留。

## 19. 驗證與重現

執行 `npm ci`、`npm run data:fetch:bridge-policy`、`npm run data:audit:bridge-policy`、`npm run data:build:bridge-policy`、`npm run data:verify:bridge-policy`、`./init.sh`、`git diff --check`。原始位元組與設定相同，連續兩次輸出逐位元組相同。實際測試、瀏覽器與大小證據見交付文件，不把本機量測當作公共主機效能保證。

## 20. 限制與後續

仍缺官方橋梁跨表、精確檢測日期、術語定義、週期適用政策、界線驗證與工程狀況。後續應取得官方識別碼對應及完整報告，再審視對帳門檻與地理範圍。現有查核名單不能授權修繕、封橋或工程認證。Portfolio Case Study 009 可展示來源保全、身分失敗案例、策略取捨與可稽核工程證據；本次不修改 Portfolio 專案。
